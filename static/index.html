📈 AI Architecture & Model Evaluation

Pipeline Overview

1. Preprocessor: Cleans tokens, extracts entities (URLs, phones, crypto, currency), computes heuristic scores.
2. TF-IDF Vectorizer: Unigrams + Bigrams (1,031 features, sublinear term frequency).
3. Soft Voting Ensemble: Logistic Regression (C=2.0) + Multinomial Naive Bayes (alpha=0.1).
4. Calibrated Output: Combines statistical probability with threat vector heuristics.
